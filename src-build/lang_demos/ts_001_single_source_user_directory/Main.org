#+STARTUP: showall

* TypeScript React Blessed User Directory

This demo keeps the user model, sample data, and directory helpers in the
XTalk source at =main.clj=. The build emits that module as JavaScript plus
TypeScript declarations. =app.tsx= consumes those generated declarations and
renders the in-memory directory with React Blessed.

The app filters users by ID, name, or role. The selected user's name, ID, and
roles appear beside the list. It does not persist or modify users.

* Generated build tree

Running =(make/build-all TS-001-SINGLE-SOURCE-USER-DIRECTORY)= writes:

- =.build/demo/ts-001-single-source-user-directory/.gitignore=
- =.build/demo/ts-001-single-source-user-directory/Makefile=
- =.build/demo/ts-001-single-source-user-directory/package.json=
- =.build/demo/ts-001-single-source-user-directory/tsconfig.json=
- =.build/demo/ts-001-single-source-user-directory/src/index.js=
- =.build/demo/ts-001-single-source-user-directory/src/index.d.ts=
- =.build/demo/ts-001-single-source-user-directory/src/app.tsx=
- =.build/demo/ts-001-single-source-user-directory/src/react-blessed.d.ts=

Installing the generated package dependencies and running =make build= creates
=dist/app.js= and copies the generated XTalk module to =dist/index.js=.
The declaration file includes callable value declarations alongside each
function type so TypeScript can import and call the generated API.

*** Generate the project files

#+BEGIN_SRC clojure :results output silent :cache no :eval no
(load-file "build.clj")
(require '[std.make :as make]
         '[lang-demos.ts-001-single-source-user-directory.build :as build])
(make/build-all build/TS-001-SINGLE-SOURCE-USER-DIRECTORY)
#+END_SRC

*** Install, compile, and type-check

#+BEGIN_SRC shell :results output silent :cache no :eval no
cd .build/demo/ts-001-single-source-user-directory
npm install
make build
make typecheck
#+END_SRC

*** Run the app

#+BEGIN_SRC shell :results output silent :cache no :eval no
cd .build/demo/ts-001-single-source-user-directory
make run
#+END_SRC

Type to filter by ID, name, or role. Use the up and down arrows to change the
selected user, =Esc= to clear the filter, and =Ctrl+C= to quit.
